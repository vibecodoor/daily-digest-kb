Reusable implementation and operating patterns — claims you can act on.

- **Template:** [`templates/template-pattern.md`](../../templates/template-pattern.md)

  `agents.md`, `context.md`) rather than one file per pattern.
- Default to extraction: add a tight claim, not a summary.
